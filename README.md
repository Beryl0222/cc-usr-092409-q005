# 邻里课堂安全协作

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.js`：只负责校验基础事件信封，不包含业务流程。
- `src/relay.js`：接送接力领域服务。监护关系、代接范围、禁交付指令、紧急联系人分别版本化；课程冻结地点、时段、在岗人员与当日有效授权；跨点调班校验容量、资质与特殊支持并防止儿童重复在点；临时监护人变更需二次核验；保护案件禁交付指令优先于普通授权；异常只冻结相关儿童的交付；签到、调班、接送回执按稳定标识幂等合并，内容变化保留待核；`RelayService.restore(events)` 支持断线恢复后继续核验与逾期升级；`investigate(child_id, as_of)` 按当时视角还原审批人、现场负责人、交付对象与未确认通知。
- `tests/`：验证样例与基础约定保持一致，并覆盖迟到禁交付、代接人撤回、并发调班、跨点接力等场景。

## 领域边界

当前资料围绕儿童保障、人员资质和跨点调班整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 本地检查

```bash
node --test
```

## 测试与构建

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

上述命令均在单个 Linux 应用容器内执行，不需要另行启动外部服务。
