# 邻里课堂安全协作

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `data/sample-relay.json`：一条完整的跨点接力事件流（由 `npm run sample` 生成）。
- `src/validator.js`：校验基础事件信封。
- `src/events.js`：事件类型与聚合类型常量。
- `src/store.js`：追加式事件存储，可选 JSONL 落盘，按 `event_id` 幂等去重。
- `src/policy.js`：四类保障文书的版本解析与有效授权计算。
- `src/service.js`：接送接力核心服务（课程冻结、交付决策、跨点调班、通知升级、断线恢复、事后调查）。
- `src/locks.js`：键控互斥锁，并发调班时按儿童与课程串行化。
- `src/domain.ts`：领域类型说明（文档级，不参与构建）。
- `tests/`：验证样例与基础约定保持一致，并覆盖核心业务规则。

## 领域边界

当前资料围绕儿童保障、人员资质和跨点调班整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 安全不变量

1. 监护关系、代接范围、禁交付指令、紧急联系人**分别版本化**，各自形成版本链。
2. 每次课程**冻结**地点、时段、在岗人员及当日有效授权快照；快照是当日基线，
   安全类撤回（代接人撤回、禁交付指令）**即时生效**，不受快照限制。
3. 跨点调班必须先确认**接收点容量、工作人员资质、儿童特殊支持**，
   同一名儿童同一时刻只能出现在一个点；调出签退与调入签到成批落盘。
4. 监护人临时变更必须**二次核验**（核验人 ≠ 登记人）才生效；
   涉及保护案件的禁交付**优先于一切普通授权**，且只能由保障负责人解除。
5. 异常（命中禁交付、陌生人接领）只**冻结相关儿童的交付**并升级，不阻断其他家庭。
6. 签到、调班、接送回执按**稳定标识**合并：重传去重，内容变化保留待核；
   断线恢复后继续未完成的核验，并升级逾期的核验、通知与未接走儿童。

## 主要流程

- **交付决策**（`attemptPickup`）：依次检查在场状态、交付冻结、禁交付指令、
  监护人/代接人授权（含窗口与接送点范围）、待核验临时变更；回执记录决策依据
  （各文书版本、命中的临时变更、核对过的禁交付指令），供事后按当时视角还原。
- **跨点接力**（`requestTransfer` → `approveTransfer` → `executeTransfer`）：
  申请按儿童串行，批准须保障负责人且复核容量/资质/特殊支持，
  执行时调出签退、调入签到、完成记录、课程变更成批写入，并通知监护人。
- **断线恢复**（`recover`）：扫描逾期核验（失效并升级）、逾期未确认通知（升级）、
  课程结束未接走儿童（升级并通知监护人与紧急联系人）、待核修订；全部幂等。
- **事后调查**（`investigate(childId, asOf)`）：按指定时刻还原谁批准了地点变化、
  现场由谁负责、向谁交付、哪些通知尚未确认、哪些核验仍在进行。

## 本地检查

```bash
node --test
```

## 测试与构建

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

重新生成接力样例：

```bash
npm run sample
```

上述命令均在单个 Linux 应用容器内执行，不需要另行启动外部服务。
